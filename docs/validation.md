# Validation record

This release contains 285 concepts, 450 standalone SVG files, 17 category sheets, a compact comparison sheet, two overview sheets, and four example diagrams.

- XML, palette, allowed SVG shapes, metadata, rendition dimensions, source hashes, and embedded brand attribution passed validation.
- A rebuild reproduced every generated byte.
- All 450 assets rendered as nonempty artwork. Expanded viewports confirmed at least 8 units of clear margin on illustrated canvases and 1 unit on compact/brand canvases.
- All 225 previous concept IDs and canonical file paths were preserved. The 198 concepts outside social/web/contact retain identical SVG bytes. The 27 former flat defaults in those categories now use cel-shaded artwork.
- Browser integration checks passed for all 285 default detail views, every category, all style filters, search, local fonts, exact SVG downloads, compact rendition switching, actual 24px previews, clipboard success/fallback, and keyboard controls.
- Desktop, 390px mobile, and 320px mobile layouts passed overflow checks. Text in all 24 generated compositions stayed within its canvas. The offline catalog made no remote requests and produced no page errors.
- All three redesigned category sheets were visually inspected, with representative new social/web/contact forms checked at actual 64px size. Cel-shaded defaults, preserved front paths, distinct material planes, social SVG downloads, and alternate mark/control selection passed targeted checks.

The validation scripts are in `scripts/`; optional raster and browser checks write their output under `.qa/`. Rendering checks use Sharp and Chromium. PowerPoint-specific import and shape conversion have not been tested in the application.
